# ShoutLog (v1.6.1)

**ファイナルファンタジーXI（Windower 4用） 募集のシャウト・エールを読み返すためのアドオン**

`ShoutLog` は、ソロで遊んでいる間に流れた募集のシャウトやエールを、見逃しても、あとから読み返せるようにするための Windower 4 用アドオンです。

* Guildwork プラグインの `/gw shouts`（サーバー全体のシャウト・エールの一覧）から、英語だけの発言を消します。日本語の募集だけが残ります。
* 自分に届いたシャウト・エールを覚えておき、流れてしまったあとでも小さな窓で読み返せます。

ゲームのサーバーへ発言・魔法・アイテムなどを送る機能はありません。主な用途は、届いた発言を読み返すことです。

## できること

### 1. `/gw shouts` の一覧から、英語だけの発言を消す
Guildwork プラグインの `/gw shouts` は、サーバー全体のシャウト・エールをチャットログに出します。別のエリアの募集も読めて便利ですが、業者の宣伝や英語の募集も一緒に並びます。

ShoutLog を読み込んでおくと、この一覧のうち、ひらがな・カタカナ・漢字を含まない発言を表示しません。日本語の発言だけが残ります。

* 対象は、`/gw shouts` を打ってから 8 秒の間に届いた、`名前[…]: 本文` の形の行だけです。それ以外の行には触りません。
* 日本人が募集を締め切るときに使う「sime」（〆 と同じ意味）という単語を含む発言は、英語でも残します。〆 などの和文の記号を含む発言も残ります。
* `//shl status` を打つと、前回の一覧で何行を表示し、何行を消したかが分かります。

### 2. あとから読み返す窓
自分に届いたシャウト・エール（今いるエリアのシャウト、届いたエール）を最大 200 件覚えておきます。`//shl` で小さな窓が開き、流れてしまった発言を読み返せます。

* ここでも、英語だけの発言は覚えません。
* 窓の上でマウスホイールを回すと、古い発言へさかのぼれます。ドラッグで移動できます。
* 同じ人が同じ発言を 10 分以内に繰り返したときは、1 行にまとめて回数を出します。
* `//shl lines 3` のように、一度に出す件数を変えられます。

### 3. 英語でも残したい人・言葉を登録する
英語の発言でも、決まった人や言葉は残せます。たとえば、ビシージの襲来を英語で知らせてくれる人がいるなら、次のように登録します。

```
//shl allow name <プレイヤー名>
//shl allow word Besieged
```

同じコマンドをもう一度打つと外れます。`//shl allow` で今の一覧が出ます。

## 必要なもの

* Windower 4（日本語クライアント）
* Guildwork プラグイン（「1. `/gw shouts` の一覧から…」を使う場合。Windower のランチャーで有効にできます）
* Guildwork のアカウント: プラグインでログインし（`/gw login`）、[guildwork.com](https://guildwork.com/) で自分のサーバーを設定しておきます。ゲーム内で `/gw shouts` を打って一覧が出れば準備完了です。

Guildwork を使わない場合でも、「2. あとから読み返す窓」は使えます。

## インストール方法

1. GitHub リポジトリを開き、**Code → Download ZIP** でファイル一式をダウンロードします。
2. ZIP を解凍し、フォルダー名を **`ShoutLog`** にします。
   ※ GitHub の ZIP は `FF11-ShoutLog-main` という名前で解凍されるので、`ShoutLog` に直してください。フォルダー名が違うと読み込めません。
3. `Windower4/addons/` に `ShoutLog` フォルダーごと置きます。
4. ゲーム内で `//lua l shoutlog` を打って読み込みます。
5. `/gw shouts` を打つと、英語だけの発言が消えた一覧が出ます。

毎回読み込むには、`Windower4/scripts/init.txt` に `lua l ShoutLog` を 1 行足します。

ほかのライブラリを入れる必要はありません。使っているものはすべて Windower に最初から入っています。

## コマンド一覧（`//shl` または `//shoutlog`）

| コマンド | 内容 |
| :--- | :--- |
| `//shl` | 窓を開く / 閉じる |
| `//shl status` | 今の設定と、前回の `/gw shouts` で表示した行数・消した行数 |
| `//shl lines <数>` | 窓に一度に出す発言の数（3〜40、初期値 12） |
| `//shl width <数>` | 窓の 1 行の幅（全角の文字数 20〜100、初期値 44） |
| `//shl size <数>` | 窓の文字サイズ（6〜40） |
| `//shl clear` | 覚えている発言を消す |
| `//shl allow` | 英語でも残す人・言葉の一覧 |
| `//shl allow name <名前>` | 残す人を足す（もう一度打つと外す） |
| `//shl allow word <言葉>` | 残す言葉を足す（もう一度打つと外す） |
| `//shl all` | 英語だけの発言も残す / 残さない（窓と `/gw shouts` の絞り込みの両方に効きます。これから受け取る分から） |
| `//shl gwfilter` | `/gw shouts` の一覧から英語だけの発言を消す ON / OFF |
| `//shl gw` | `/gw shouts` を打ったとき、Guildwork に渡さずこの窓を開く ON / OFF（Guildwork を使わない人向け。使う人は OFF のまま） |

`//shl help` で、コマンドの一覧が出ます。

## 注意事項

* このアドオンは Guildwork とは無関係の個人作です。`/gw shouts` の出力の形（`名前[…]: 本文`）に合わせて作っているので、プラグインの更新で形が変わると、絞り込みが働かなくなることがあります。そのときは一覧がそのまま出るだけで、ほかに影響はありません。
* `/gw shouts` の一覧では、定型文だけの発言は消えます。Guildwork 経由の発言は定型文が英語で届くので、日本人が定型文だけで話した発言も英語として扱われます（自分に直接届いた発言は、定型文を日本語に直して判定するので、窓に残ります）。
* 窓に出るのは、アドオンを読み込んだあとに自分へ届いた発言だけです。覚えている発言は、読み込み直すかログアウトすると消えます。発言はファイルに残しません（設定と、英語でも残す人・言葉の一覧は `data/settings.xml` に保存します）。
* 表示とチャットの文言は日本語だけです。
* Windower を含む外部ツールの利用は、FFXI の利用規約で認められていません。このアドオンが規約に反しないこと、検知されないことは、保証できません。理解した上で、自己責任で使ってください。使用による不利益について、作者は責任を負いません。Guildwork のサービスや出力の形が変わると、一覧の絞り込みは動かなくなります。
